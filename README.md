# E-commerce Sales Analysis

An end-to-end exploratory data analysis of e-commerce sales data, built with
Python, Pandas and Plotly in Jupyter Notebook. The project cleans and transforms
raw sales data, then analyzes revenue, product performance, customer behavior
and regional trends to support data-driven business decisions.

## Objectives
- Identify top and bottom performing categories and sub-categories
- Track sales and profit trends over time
- Compare performance across regions
- Understand customer buying behavior

## Tech Stack
Python · Pandas · NumPy · Plotly · Jupyter Notebook

## Highlights
- Cleaned and prepared the dataset (missing values, duplicates, date formats)
- Built interactive Plotly charts for sales by sub-category, time and region
- Found that Phones and Chairs lead sales (~330k each), while Fasteners,
  Labels and Envelopes contribute the least
